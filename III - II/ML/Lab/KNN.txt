Building machine learning models from scratch can be complex and time-consuming. However with the right tools and frameworks this process can become significantly easier. Scikit-learn is one such tool that makes machine learning model creation easy. It provides user-friendly tools for tasks like Classification, Regression, Clustering and many more.


scikit-learn (formerly scikits.learn and also known as sklearn)

Scikit-learn is a free, open-source Python library that helps users build machine learning models. It's a popular tool for data scientists and programmers. 

Scikit-learn (sklearn) is a machine learning library for Python that's used to build and deploy models. It's used for classification, regression, clustering, and more. 

 It features various classification, regression and clustering algorithms including support-vector machines, random forests, gradient boosting, k-means and DBSCAN, and is designed to interoperate with the Python numerical and scientific libraries NumPy and SciPy. Scikit-learn is a NumFOCUS fiscally sponsored project
What can you do with scikit-learn?
Classification: Identify which category an object belongs to, such as spam detection 
Regression: Predict a continuous variable based on other variables, such as housing prices 
Clustering: Automatically group similar objects into sets, such as customer segmentation 
Dimensionality reduction: Simplify complex datasets by reducing the number of variables 
Model selection: Compare different machine learning algorithms and tune their settings 
Data preprocessing: Prepare data for machine learning algorithms, such as transforming text into numerical features 
Features of scikit-learn 
Open-source
Built on NumPy, SciPy, and matplotlib
Includes tools for model fitting, evaluation, and selection
Offers a consistent Python interface
Has extensive documentation and online tutorials

Step 1: Load a Dataset
A dataset is nothing but a collection of data. A dataset generally has two main components: 

Features: They are also known as predictors, inputs or attributes. These are simply the variables of our data. They can be more than one and hence represented by a feature matrix (‘x’ is a common notation to represent feature matrix). A list of all the feature names is termed feature names.
Response: They are also known as the target, label or output. This is the output variable depending on the feature variables. We generally have a single output variable column and it is represented by a response vector ( ‘y’ is a common notation to represent response vector). All the possible values taken by a response vector are termed target names.

Euclidean Distance Formula
Consider two points (x1, y1) and (x2, y2) in a 2-dimensional space; the Euclidean Distance between them is given by using the formula:

d = √[(x2 - x1)2 + (y2 - y1)2]

Where,

d is Euclidean Distance
(x1, y1) is Coordinate of the first point
(x2, y2) is Coordinate of the second point
