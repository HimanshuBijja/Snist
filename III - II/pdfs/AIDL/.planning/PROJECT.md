# Project AIDL Analysis

## Overview
This project aims to analyze a collection of Artificial Intelligence and Deep Learning (AIDL) PDFs to generate 8-mark and 2-mark question-answer sets.

## Objectives
- Analyze each PDF in the workspace.
- Generate important 8-mark answers with individual copy buttons (Markdown-compatible).
- Generate important 2-mark answers grouped together with a single copy button.
- Store each file's analysis in a separate file within the `gsd-analysis` directory.

- PDF Parsing: TBD (likely Python or Node-based)
- Analysis: LLM-based (Gemini)
- Output: Markdown with HTML snippets for "Copy" functionality.
